# Intrinsic Bio-Sensing of Trees — Backend

FastAPI backend for the IEEE YESIST12 tree bio-sensing project.

## Setup
1. Create venv: `python -m venv venv`
2. Activate it, then `pip install -r requirements.txt`
3. Copy `.env.example` to `.env` and set `DATABASE_URL`
4. Run: `uvicorn app.main:app --reload` (from `backend/`)
